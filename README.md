# PAYDEUK_WEB

## 프로젝트 개요
혜택 기반 카드 추천 및 간편 결제 서비스입니다.  
사용자는 간편하게 본인인증 후 카드를 등록하고,  
추천 카드 기반으로 결제 후 내역을 관리할 수 있습니다.  
관리자는 대시보드에서 가맹점과 사용자의 통계를 조회할 수 있습니다.
